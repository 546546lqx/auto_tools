# YOLO 数据工具箱

一个基于 Flask 的本地 YOLO 数据处理工具箱，面向图片数据集、标注文件、视频抽帧和自动标注等常见工作流，提供统一的网页界面来完成日常数据准备任务。

## 功能概览

- **数据统计**：统计图片、标注、类别分布、空标注等信息。
- **数据清理**：查找并处理孤立图片、孤立标注文件等常见脏数据。
- **数据划分**：将数据集划分为 `train / val / test`。
- **批量重命名**：统一图片和标注文件命名规则。
- **格式转换**：支持常见标注格式转换为 YOLO 需要的格式。
- **视频与 RTSP 抽帧**：从本地视频或 RTSP 源中按间隔提取图片。
- **多边形标注**：绘制多边形区域并导出点位信息。
- **自动化标注**：加载本地模型，对图片批量推理并生成 YOLO 标注文件。
- **桌面文件选择**：提供本地路径选择辅助能力，减少手动输入路径。

## 项目结构

```text
application/
├── blueprints/      # Flask 路由与页面入口
├── services/        # 各功能对应的业务逻辑
├── static/          # JS、CSS 等前端静态资源
├── templates/       # Jinja2 页面模板
├── utils/           # 公共工具函数
├── config.py        # 配置项
├── extensions.py    # 扩展初始化
└── __init__.py      # 应用工厂

models/
└── yolo26n.pt       # 示例/本地模型文件

tools/               # 独立脚本工具
run.py                # 启动入口
requirements.txt      # 依赖列表
```

## 环境要求

- Python 3.10+
- Windows / Linux / macOS 均可
- 建议使用虚拟环境

## 依赖安装

```bash
pip install -r requirements.txt
```

当前核心依赖包括：

- `Flask`
- `opencv-python`
- `ultralytics`

## 运行方式

在项目根目录执行：

```bash
python run.py
```

默认会启动本地开发服务器：

- 地址：`http://127.0.0.1:5000`
- 调试模式：开启

## 使用说明

1. 启动服务后，在浏览器中打开首页。
2. 通过顶部导航进入对应功能页面。
3. 按页面提示选择本地图片目录、标注目录、视频源或模型文件。
4. 执行任务后，在页面中查看结果或下载生成文件。

## 自动标注功能说明

自动标注页面依赖本地模型和类别映射关系：

- 模型文件支持 `pt`、`onnx`、`engine`、`tflite` 等格式。
- 需要填写类别映射，例如：

```text
person-->0
car-->1
```

- 程序会读取图片目录中的所有图片，并为每张图生成对应的 YOLO `.txt` 文件。

## 视频抽帧功能说明

视频页面支持：

- 本地视频文件
- RTSP 流地址
- 自定义抽帧间隔
- 选择输出格式
- 任务开始后可查询进度或停止任务

## 开发提示

- 应用采用 Flask 工厂模式创建，入口在 `application/__init__.py`。
- 路由按功能拆分到不同 blueprint，便于后续扩展。
- 业务逻辑主要集中在 `application/services/`。
- 前端页面使用模板 + 原生 JavaScript 组织。

## 注意事项

- 这是一个本地数据处理工具，建议在离线或受控环境中运行。
- 自动标注需要安装并正确配置 `ultralytics` 及可用模型。
- 处理数据前建议先备份原始数据集。
